# GPSSpeed

Aplicativo Android de velocímetro por GPS com registro de percurso.

## Objetivos iniciais

- Mostrar velocidade atual em km/h
- Registrar velocidade máxima e média
- Calcular distância percorrida
- Cronometrar o percurso
- Gravar pontos de GPS do trajeto
- Exibir o caminho percorrido em mapa
- Salvar histórico de viagens

## Estrutura planejada

- `index.html` — tela principal
- `css/style.css` — visual do aplicativo
- `js/app.js` — controle geral
- `js/gps.js` — leitura do GPS
- `js/speedometer.js` — cálculos do velocímetro
- `js/tracking.js` — gravação do trajeto
- `js/trips.js` — histórico de viagens
- `js/map.js` — mapa e rota
- `js/database.js` — armazenamento local
- `js/settings.js` — configurações
- `js/utils.js` — funções auxiliares
- `pages/` — telas secundárias

Projeto iniciado em agosto de 2026.
